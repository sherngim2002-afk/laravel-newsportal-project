# Jawaaf News Portal (Clone)

A web application developed as a clone of the **Jawaaf News Portal** ([jawaaf.com](https://jawaaf.com)). This project replicates core content management workflows, news categorizations, and article rendering using **Laravel 11** and **Filament PHP**.

> **Note & Disclaimer:** This project is created strictly for educational, learning, and portfolio demonstration purposes as a functional clone of the Jawaaf News platform. All original branding, media concepts, and layouts belong to Jawaaf News.

---

## Key Features

- **Jawaaf Portal Layout Replica:** Customized Blade layouts and components mimicking the dynamic news sections of Jawaaf.
- **Admin Management Panel:** Powered by Filament PHP for creating, updating, and categorizing news articles and managing ad spaces.
- **Content Categorization:** Organizes news into custom categories (e.g., Politics, Society, Technology, Entertainment).
- **RESTful API Integration:** Endpoints configured for mobile or external content consumption.
- **Dashboard Analytics:** Admin widgets tracking article rates and overview metrics.

---

## Tech Stack

- **Framework:** Laravel 11.x
- **Admin Panel:** Filament v3
- **Database:** MySQL / MariaDB
- **Frontend / Styling:** Tailwind CSS, Blade Components, Vite
- **Testing:** Pest PHP
